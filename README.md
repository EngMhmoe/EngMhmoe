# 💫 About Me:
Front-End Developer specializing in building modern, responsive, and user-friendly websites and web applications using React.js, JavaScript, HTML5, CSS3, Tailwind CSS, and Bootstrap. I have practical experience developing reusable React components, integrating REST APIs, managing application state, implementing client-side routing, and working with Strapi for dynamic content management.<br><br>I focus on writing clean, maintainable, and well-structured code while creating responsive interfaces that provide a consistent user experience across different devices. Through academic study, practical training, and personal projects, I have developed experience in building real-world web applications, including travel platforms, task management systems, weather applications, and personal portfolio websites.<br><br>I am also currently expanding my back-end development knowledge through ongoing .NET training, learning C#, ASP.NET Core, Web APIs, databases, and Entity Framework Core. My goal is to continue developing my skills and building reliable, practical web solutions with a strong focus on performance, usability, and code quality.
